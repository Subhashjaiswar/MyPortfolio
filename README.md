# Subhash Jaiswar Portfolio

React + Vite portfolio created from the supplied resume.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```

## Customize

- Replace the placeholder GitHub/LinkedIn links in `src/main.jsx`.
- Add a resume PDF to `public/` and connect the Download Resume button.
- Update project descriptions or screenshots as needed.
